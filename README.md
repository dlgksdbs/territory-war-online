# 🌐 영토 전쟁 ONLINE · 실시간(RTS)

한 손으로 즐기는 **실시간 영토 확장 전략 게임**입니다. 차례를 기다리는 턴제가 아니라, 병력이 계속 생산되고 부대가 지도 위를 행군하는 **실시간 RTS**입니다. 친구와 방 코드 하나로 만나 2~4인이 겨루고, 남는 자리는 AI가 맡습니다. 서버가 모든 판정을 담당하는 **Node.js + WebSocket** 멀티플레이 버전입니다.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/dlgksdbs/territory-war-online)

## ✨ 이런 게임이에요

- **턴 없음 · 실시간** — 100ms 서버 시뮬레이션이 계속 돌아갑니다. 내 영토는 저마다 병력을 생산하고(수도는 1.75배), 전투와 외교도 초 단위로 흐릅니다.
- **2탭 출정** — 내 영토를 탭하고 옆 영토를 탭하면 바로 출정. 아래에서 **25% / 50% / 75% / 100%** 로 한 번에 보낼 병력을 고릅니다(기본 50%).
- **행군하는 부대** — 보낸 병력은 **1.2초** 동안 지도 위를 이동한 뒤 도착해 합류하거나 싸웁니다. 행군 중인 부대는 진영 색과 병력 수로 표시됩니다.
- **28개 영토 · 보로노이 지도** — 매 판 새로 생성되는 대륙, 영토마다 병력 상한(9~14)과 생산 속도가 있습니다.
- **실시간 외교** — 불가침 45초 · 동맹 60초 · 조공 45초(12초마다 지급) · 공동 참전 30초. 남은 시간이 실시간으로 줄어듭니다. 관계(-100~+100)와 신뢰도(0~100), 배신의 대가까지.
- **⚔️ 칼들고 참전 (직접 전투 · 3D)** — 지도 아래 **칼들고 참전**을 누르면 그 전선에 병사로 뛰어들어 **1인칭 3D(Three.js WebGL) 칼싸움**을 직접 합니다. 홈 화면의 **⚔️ 대규모 3D 전장** 버튼으로 지도 없이 100명 규모 난전도 바로 시작할 수 있습니다. 3D를 못 켜는 기기에서는 예전 2D 탑다운으로 자동 전환됩니다. 적을 베면 지도 위 적 병력이 실제로 줄고, 6명마다 우리 전선 병력이 늘며 적 수비가 약해집니다. 자세한 내용은 [칼들고 참전](#-칼들고-참전-직접-칼질-전투) 참고.
- **🤖 AI 시뮬레이션 (관전 + 난입)** — 시작 화면에서 누르면 4개국 AI가 실시간으로 난전합니다. 구경하다가 마음에 드는 나라를 골라 **⚔️ 이 나라로 참전**하면 그 나라를 직접 조종합니다. 속도 **×1 · ×2 · ×4**.
- **🤖 AI 위임** — 혼자 하는 판에서는 내 나라를 AI에게 맡기고 구경하다가 **조종 가져오기**로 언제든 돌아옵니다.
- **전략적인 AI** — 1.8~3.2초마다 판단해 약한 곳을 노려 출정하고, 후방 병력을 전선으로 모으며, 들어오는 행군을 보고 수비 병력을 보냅니다. 1위 국가가 나오면 연합해 견제합니다.
- **자리 유지** — 휴대폰이 앱을 전환해 연결이 끊겨도 다시 열면 원래 자리로 돌아옵니다. 25초 넘게 끊기면 AI가 잠시 대신 조종합니다.

## 🚀 1분 만에 실행

Node.js **18 이상**이 필요합니다.

```bash
cd territory-war-online
npm install
npm start
```

브라우저에서 **http://localhost:3000** 을 엽니다.

같은 Wi-Fi의 친구와 하려면 내 컴퓨터의 LAN IP로 접속하면 됩니다.

```bash
# macOS / Linux
hostname -I
# 예: http://192.168.0.12:3000
```

> 포트를 바꾸려면 `PORT=8080 npm start`

| 보낼 병력 양 | 하단 **25 / 50 / 75 / 100%** (100%는 1개 남김) |

| AI에게 맡기기 | 메뉴 → **🤖 AI 위임** / HUD의 **조종 가져오기** |
| 관전으로 돌아가기 | 메뉴 → **👁 관전으로 돌아가기** (시뮬레이션) |
| 다른 나라 참전 | 시뮬레이션 관전 중 하단 국가 버튼 → **⚔️ 이 나라로 참전** |
| 병사로 직접 칼싸움 | 하단 **⚔️ 칼들고 참전** (고른 영토 또는 가장 센 전선) |

### 전투 규칙

- 수비 측은 **1.15배**(수도 1.3배) 유리합니다. 공격력이 수비력을 넘으면 영토를 차지하고 남은 병력이 주둔합니다.
- 공격에 실패해도 수비 병력은 줄어듭니다. 여러 방향에서 한 영토로 병력을 모으면 상한을 넘겨 쌓을 수 있습니다.
- 동맹과 공동의 적을 칠 때는 공격력이 **+12%** 됩니다.
- 상한 근처(75% 이상)에서는 생산이 느려집니다. 6분이 지나면 '결전 모드'로 생산이 가속합니다.

## ⚔️ 칼들고 참전 (직접 칼질 전투)

지도에서 지휘만 하던 나라를 잠깐 내려가 **병사 한 명**이 되어 전선에서 직접 싸웁니다. 지도는 그동안에도 계속 돌아가고, 아레나에서 벤 만큼이 지도에 바로 반영됩니다.

### 들어가고 나오기
- 하단 **⚔️ 칼들고 참전** — 고른 내 영토(없으면 가장 센 전선)와 맞닿은 적 영토로 참전합니다. 버튼 아래에 `영토 ↔ 적 영토 · 적 병력` 이 표시됩니다.
- **🗺️ 지도로 복귀** — 언제든 지도로 돌아옵니다. 적을 모두 베면 **전선 돌파**로 자동 종료됩니다.
- 조약 중인 나라, 옆에 적이 없는 내부 영토, AI 위임·관전 중에는 참전할 수 없습니다. 한 번 참전하고 **6초** 쉬어야 다시 들어갑니다.

### 조작 (모바일 우선)
| 하고 싶은 것 | 방법 |
|---|---|
| 이동 | 화면 **왼쪽 절반 아무 곳이나 드래그** (가상 조이스틱) · 데스크톱 `WASD`/방향키 |
| ⚔️ 칼 휘두르기 | 오른쪽 절반 **탭** 또는 **⚔️ 베기** 버튼 · `Space`/`J` |
| 💨 돌진 베기 | **💨 돌진** 버튼 (1.5초 쿨) · `Shift`/`K` |
| 🛡️ 막기 / 패링 | **🛡️ 막기** 를 누르고 있는 동안 피해 75% 감소, 공격 **직전 0.26초**에 누르면 **패링**(피해 0 · 상대 경직) |
| 지도로 | **🗺️ 지도로 복귀** · `Esc` |

### 3D 전장 (Three.js · WebGL) · 1인칭
- **시점** — 병사 눈높이(≈20.5)의 **1인칭** 카메라입니다. 내 3인칭 몸은 그리지 않고, 화면 앞에 **오른손 검 · 왼손 방패 뷰모델**(걷기 흔들림 · 대각선 베기 궤적 · 돌진 런지 · 방패 올리기)을 그립니다.
- **시점은 내가 돌릴 때만** — **왼쪽 드래그**는 지금 보는 방향 기준으로 이동만 하고 시점은 절대 돌리지 않습니다. **오른쪽 드래그**로만 좌우(yaw)·상하(pitch) 시점이 돌아가고, 오른쪽 **짧은 탭**은 베기입니다. 데스크톱은 `WASD` 이동 · `←→` 시점 · 위아래 화살표 고개 · `Space/J` 베기 · `Shift/K` 돌진 · `L` 막기.
- **세로 화면** — 390×844에서도 수평 화각 45°+가 나오도록 수직 화각을 72~92°로 자동 조정하고, 조준선·화면 밖 적 방향 화살표·위험 시 붉어지는 조준선으로 접근을 읽습니다.
- **전장** — 흙길이 난 초원 지형, 진영 색 띠, 경계 말뚝, 바위·천막·수레 같은 3D 장애물, 펄럭이는 진영 깃발과 화톳불, 먼 산 실루엣.
- **병사** — 몸통 갑옷 · 투구 · 오른손 칼 · 왼손 방패 · 발밑 그림자까지 절차적으로 만든 3D 메시. 걷기/달리기 다리 애니메이션, 칼 휘두르기 궤적, 돌진 자세, 방패 올리기(막기)가 그대로 보입니다. 1인칭에서는 **적·아군이 칼을 치켜들고(붉은/푸른 검기 예고) 휘두르는 동작**이 정면에서 읽혀서 🛡️ 막기·패링 타이밍을 잡을 수 있습니다.
- **대규모 난전** — 병사는 **InstancedMesh(지오메트리·재질 공유)** 로 그려 수십~수백 명도 드로우콜 수십 개로 유지합니다. 홈 화면 **⚔️ 대규모 3D 전장 · 바로 싸우기** 를 누르면 지도 없이 **700×1500** 대형 전장에서 적 56 · 아군 50이 파도처럼 증원되고 한 화면에 30명 안팎이 맞붙습니다. [🔁 다시 싸우기] · [🗺️ 홈으로] 로 바로 이어서 즐깁니다.
- **검기** — 가슴 높이에서 회전하는 칼자국 크레센트 + 지면을 타고 퍼지는 충격 링 + 스파크.
- **3D 두 동강** — 적을 베면 **칼이 지나간 각도 그대로** 3D 병사 메시를 절단면으로 잘라 **정확히 두 조각**으로 만듭니다. 조각은 칼날에 수직인 방향으로 튕겨 나가 공중에서 회전하고, 잘린 단면(결이 보이는 살점)과 칼날 섬광선이 남았다가 약 0.95초 뒤 사라집니다.
- **자동 폴백** — WebGL/Three.js 를 못 쓰면(`TWArena3D.supported() === false`) 또는 3D 초기화·컨텍스트 손실 시 기존 2D 렌더러로 그대로 전환됩니다. 게임 규칙·서버 검증은 두 모드가 완전히 동일합니다.
- **로컬 번들** — `public/vendor/three.module.min.js` (three r169) 를 서버가 직접 서빙합니다. 외부 CDN 이 필요 없어 모바일에서 로딩 실패가 없습니다.

### 전투 감각
- **콤보** — 2.2초 안에 연속으로 베면 콤보가 쌓이고 데미지가 최대 +38까지 오릅니다. 5콤보마다 화면이 울립니다.
- **히트스톱 · 스파크 · 넉백** — 벨 때마다 짧게 멈추고 불꽃이 튑니다.
- **두 동강** — 칼이 지나간 **각도 그대로** 적이 두 조각으로 갈라집니다. 조각은 칼날에 수직인 방향으로 벌어져 회전하며 약 0.95초 동안 날아간 뒤 사라지고, 절단면에는 섬광선이 남습니다.
- **쓰러져도 끝나지 않음** — HP 0이면 2초 뒤 아군 진영에서 부활합니다(베기 기록 유지). 지도에서의 판은 그대로입니다.

### 베면 지도가 바뀐다 (서버 검증)
| 결과 | 규칙 |
|---|---|
| 적 병력 감소 | **3명 처치 = 적 병력 1** 감소. 한 번 참전에 대상 병력의 45%(최대 6)까지만, 병력 1은 남깁니다 |
| 전선 병력 합류 | **6명마다** 우리 전선 영토 병력 +1 (최대 +4) |
| 수비 약화 | **6명**을 베면 그 영토 수비가 **22초 동안 -22%** (다음 출정이 쉬워짐) |
| 전선 돌파 | 적을 모두 베고 나오면 피해 한도 안에서 보너스 1 |
| 검증 | 클라이언트가 보고한 킬은 서버가 **초당 5킬 + 여유 4킬** 상한으로 자릅니다. 비정상 보고는 깎이고 `flagged` 로 기록됩니다. 최대 참전 시간 150초 |

아레나의 실시간 전투는 화면에서 돌지만 **병력·점령에 영향을 주는 계산은 전부 서버**가 검증해 적용합니다.

## 🧠 실시간 구조

```
server.js          Node.js + ws 단일 서버 (지도 생성 · 시뮬레이션 · WebSocket)
public/index.html  화면 골격
public/app.js      캔버스 렌더 · 터치 · WebSocket 클라이언트
public/arena.js    직접 참전 아레나 시뮬레이션 · 입력 · HUD · 2D 렌더러(폴백)
public/arena3d.js  Three.js 3D 렌더러 (전장·병사·검기·3D 두 동강)
public/vendor/     three.module.min.js (r169, MIT) 로컬 번들
public/style.css   모바일 다크/택티컬 UI
test/smoke.js      엔진 · 헤드리스 AI 시뮬레이션 · WebSocket 스모크 테스트
test/mobile-arena.js   모바일(390×844) 헤드리스 브라우저 검증 · 스크린샷
test/mobile-arena3d.js 3D(WebGL) 아레나 검증 · 3D 스크린샷
```

- **시뮬레이션**: `Sim.step(state, dt)` 가 병력 생산 → 행군 도착/전투 → 외교 타이머 → AI 판단 순으로 처리합니다. 헤드리스로 수백 배 빠르게 돌려 검증할 수 있습니다.
- **동기화**: 시작·재접속 때는 전체 `state`(폴리곤 포함), 플레이 중에는 400ms마다 압축 `tick`(영토 `[주인, 병력]`, 행군, 조약 남은 시간, 제안, 관계, 군세)을 보냅니다.
- **권위**: 병력·전투·외교·AI는 모두 서버가 결정합니다. 클라이언트는 표시와 요청만 합니다.
- **AI 시뮬레이션**: 4개국 모두 `human=false`로 시작하고, `takeover` 메시지로 한 나라를 사람이 넘겨받습니다. `delegate` 로 다시 AI에게 맡길 수 있습니다.

### WebSocket 메시지 요약

| 방향 | 타입 |
|---|---|
| 클라이언트 → 서버 | `create`(sim 옵션) · `join` · `resume` · `start` · `sim` · `action`(send/respond/propose/alliance/tribute/cede/call/aid/break/speed) · `takeover` · `delegate` · `spectate` · `speed` · `aiFill` · `rematch` · `leave` · `ping` · `skirmish`(start/report/end) |
| 서버 → 클라이언트 | `joined` · `resumed` · `lobby` · `started` · `state` · `tick` · `event` · `error` · `left` · `pong` · `skirmish_start` · `skirmish_update` · `skirmish_end` |

## ☁️ 배포

### Render (가장 쉬움)

위의 **Deploy to Render** 버튼 → 저장소 선택 → 그대로 배포. `render.yaml` 이 `npm install` · `node server.js` · 헬스체크 `/healthz` 를 자동 설정합니다.

### Railway

1. [railway.app](https://railway.app) → **New Project → Deploy from GitHub repo** → 이 저장소 선택
2. 자동으로 `npm install` → `node server.js` 로 실행됩니다 (`PORT` 는 Railway가 주입)
3. **Settings → Networking → Generate Domain** 으로 공개 주소 발급

### Docker

```bash
docker build -t territory-war .
docker run -p 3000:3000 territory-war
```

### 환경 변수

| 키 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `3000` | HTTP/WebSocket 포트 (Railway·Render 자동 주입) |

서버는 `0.0.0.0` 에 바인딩하며, WebSocket 은 같은 포트의 `/ws` 를 사용합니다. 인메모리 방 저장이라 재배포 시 진행 중인 방은 초기화됩니다.
