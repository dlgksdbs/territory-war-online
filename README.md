# 🌐 영토 전쟁 ONLINE

한 손으로 즐기는 **실시간 영토 확장 전략 게임**입니다. 친구와 방 코드 하나로 만나 2~4인이 겨루고, 남는 자리는 AI가 맡습니다. 서버가 모든 판정을 담당하는 **Node.js + WebSocket** 멀티플레이 버전입니다.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/dlgksdbs/territory-war-online)

---

## ✨ 이런 게임이에요

- **28개 영토 · 보로노이 지도** — 매 판 새로 생성되는 대륙을 두고 4개국이 다툽니다.
- **한 손 모바일 조작** — 영토를 탭해 병력을 배치하고, 이웃을 탭해 공격·이동합니다. 세로 화면에 맞춘 UI.
- **실시간 방** — `방 만들기`로 4자리 코드를 만들고, 친구는 코드를 입력해 바로 참가합니다.
- **자리 유지** — 휴대폰이 앱을 전환해 연결이 끊겨도 같은 기기에서 다시 열면 원래 자리로 돌아옵니다.
- **깊어진 외교** — 관계도·신뢰도, 불가침 → 동맹, 공동 참전, 조공, 영토 할양, 배신의 대가까지.
- **전략적인 AI** — 병력을 전선에만 배치하고, 후방 병력을 끌어오고, 유리할 때만 공격하며, 1위 국가를 견제합니다.

## 🚀 1분 만에 실행

Node.js **18 이상**이 필요합니다.

```bash
cd territory-war-online
npm install
npm start
```

브라우저에서 **http://localhost:3000** 을 엽니다.

같은 Wi-Fi의 친구와 하려면 내 컴퓨터의 LAN IP로 접속하면 됩니다.

```bash
# macOS / Linux
hostname -I
# 예: http://192.168.0.12:3000
```

> 포트를 바꾸려면 `PORT=8080 npm start`

## ☁️ 무료 배포 (1분)

### Render — 가장 쉬움 (권장)

가장 빠른 길은 위의 **Deploy to Render** 버튼입니다. 누르면 Render가 이 저장소를 읽어 `render.yaml` 그대로 서비스를 만듭니다(무료 플랜, `/healthz` 헬스체크, 자동 배포). Render 계정이 없으면 GitHub로 로그인하면 되고, 카드는 필요 없습니다.

직접 설정하려면:

1. 이 폴더를 GitHub 저장소에 올립니다.
2. [render.com](https://render.com) → **New → Web Service** → 저장소 선택.
3. Render가 `render.yaml`을 읽어 자동 설정합니다. 직접 설정할 경우:
   - **Environment**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `node server.js`
   - **Plan**: Free
4. 배포가 끝나면 `https://내서비스.onrender.com` 주소가 나옵니다. 이 주소를 친구에게 보내면 끝!

> Render 무료 플랜은 15분간 요청이 없으면 잠들고, 다음 접속 때 30초쯤 걸려 깨어납니다. WebSocket은 무료 플랜에서도 지원됩니다.

### Railway

1. [railway.app](https://railway.app) → **New Project → Deploy from GitHub repo**.
2. 저장소를 고르면 `package.json`의 `start` 스크립트로 자동 실행됩니다.
3. **Settings → Networking → Generate Domain** 으로 공개 주소를 만듭니다.

### Fly.io — Dockerfile 사용

```bash
fly launch --no-deploy     # 앱 이름 지정, Dockerfile 자동 감지
fly deploy
fly open
```

`Dockerfile`이 `PORT` 환경변수를 그대로 사용하므로 별도 설정이 필요 없습니다.

> 무료 호스팅은 콜드 스타트·슬립·트래픽 제한이 있을 수 있습니다. 방 상태는 서버 메모리에 있으므로 **서버가 재시작되면 진행 중인 방은 닫힙니다.** (같은 기기에서 다시 열면 자동 복귀를 시도하고, 방이 사라졌으면 로비로 돌아갑니다.)

## 🎮 게임 방법

### 방 만들기 / 참가

| 단계 | 설명 |
|---|---|
| 1 | 이름을 입력하고 **방 만들기** — 4자리 코드가 생깁니다. |
| 2 | 친구는 코드를 입력하고 **참가** — 최대 4명. |
| 3 | 방장이 **빈 자리 AI로 채우기**를 켜면 남는 나라는 AI가 맡습니다. (끄면 남는 나라는 중립) |
| 4 | 방장이 **게임 시작**. 2명 이상이면 AI 없이도 시작할 수 있습니다. |

### 한 손 조작

- **병력 배치** 상태에서 내 영토를 탭 → `+1` (오른쪽 `+1 / 전부` 버튼으로 방식 전환)
- **공격 · 이동** 상태에서 병력 2 이상인 내 영토를 탭 → 이웃이 빨강(공격)·초록(이동)·노랑(조약)으로 표시
- 빨간 이웃을 탭하면 **주사위 전투** (공격 최대 3개, 수비 최대 2개, 동점은 수비 승)
- 병력이 0이 되면 영토를 점령하고 병력이 이동합니다.
- **턴 종료** — 배치가 남아 있으면 한 번 더 눌러 확인합니다.

내 차례가 아니어도 지도를 탭하면 영토·소유자·병력·조약을 볼 수 있습니다.

## 🤝 외교 시스템

외교 창에서 상대마다 **관계(-100~+100)** 와 **신뢰도(0~100)**, 현재 조약, 최근 외교 소식을 한눈에 봅니다.

### 관계와 신뢰도

| 행동 | 관계 | 신뢰도 |
|---|---:|---:|
| 병력 지원 (+3) | **+15** | +3 |
| 조공 이행 (매 라운드) | +4 | +2 |
| 영토 할양 | **+25** | +5 |
| 공동 참전 수락 | +10 | +2 |
| 공격·점령 | −6 ~ −12 | — |
| **조약 파기(배신)** | **−55** | **−35** |
| 배신 소문 (제3국) | −8 | — |

신뢰도가 낮은 나라는 AI가 **불가침·동맹 제안을 거절**할 확률이 크게 높아집니다. 배신은 게임 내내 따라다닙니다.

### 조약의 종류

| 조약 | 지속 | 효과 |
|---|---:|---|
| **불가침** | 4턴 | 서로 공격 금지 |
| **동맹** | 5턴 | 공격 금지 + 공동의 적 공격 시 **주사위 +1** + **공동 참전 요청** |
| **조공** | 4턴 | 매 라운드 1~2개 병력 이전 + 공격 금지 |

- **불가침 → 동맹**: 불가침이 맺어진 상대에게 `동맹` 버튼이 열립니다.
- **공동 참전**: 동맹에게 특정 적을 지정해 함께 공격하도록 요청합니다. AI 동맹은 관계가 높으면 다음 턴부터 그 적을 우선 공격하고, 사람 동맹에게는 **실시간 수락/거절 창**이 뜹니다.
- **조공**: `조공 요구`(상대가 나에게 바침) 또는 `조공 제안`(내가 상대에게 바침)을 고르고 1~2개를 정합니다. 약속을 이행하지 못하면 조약이 깨지고 신뢰도를 잃습니다.
- **영토 할양**: 내 영토 하나를 넘겨 관계 +25를 얻고, 원하면 불가침까지 함께 맺습니다. 상대 국경과 맞닿은 영토일수록 AI가 잘 받아들입니다.
- **조약 파기**: 즉시 공격 가능해지지만 신뢰도 −35, 관계 −55, 상대의 원한(6턴)을 삽니다.

모든 제안은 **WebSocket으로 실시간 전달**되며, 상대가 자기 차례가 아니어도 수락/거절할 수 있습니다.

## 🤖 AI는 이렇게 둡니다

- **전선 배치**: 보충 병력을 내부 영토에 넣지 않고, 적과 맞닿은 전선 중 위협·공격 기회가 큰 곳에 70/30으로 나눠 배치합니다.
- **후방 → 전선 이동**: 전선까지의 거리를 계산해, 안전한 내부의 남는 병력을 전선으로 끌어옵니다. 한가한 전선에 쌓인 병력도 위협 전선으로 옮깁니다.
- **신중한 공격**: 적국은 `내 병력 ≥ 적 + 2`, 중립은 `+1` 우위일 때만 공격합니다. 약한 이웃 마무리, 초반 중립 확장, 공동 참전 목표, 배신자를 우선합니다.
- **과확장 방지**: 점령 직후 1개만 남는 영토가 큰 적 부대에 둘러싸이면 공격을 피합니다.
- **전략 외교**: 한 나라가 영토 35% 이상을 차지하면 다른 나라들과 휴전·동맹을 맺어 견제하고, 두 전선에 몰리면 약한 쪽과 휴전하거나 조공을 바칩니다. 강한 이웃에게는 조공을 요구하고, 동맹에게 공동 참전을 요청합니다.

## 🗂 구조

```
territory-war-online/
├─ server.js              # HTTP + WebSocket + 권위 게임 엔진/AI/외교
├─ public/
│  ├─ index.html          # 로비 · 게임 · 외교 · 결과 화면
│  ├─ app.js              # 클라이언트 (Canvas 렌더 · 입력 · 소켓)
│  ├─ style.css           # 다크 전략 테마 (모바일 우선)
│  ├─ manifest.webmanifest
│  └─ icon-192.png / icon-512.png / favicon.svg
├─ test/smoke.js          # 엔진 + WebSocket 스모크 테스트
├─ render.yaml            # Render 무료 배포 설정
├─ Dockerfile             # Fly.io / Railway / Docker
└─ package.json
```

### 통신 요약

| 방향 | 메시지 |
|---|---|
| 클라이언트 → 서버 | `create`, `join`, `resume`, `start`, `aiFill`, `action`, `rematch`, `leave` |
| 서버 → 클라이언트 | `joined`, `resumed`, `lobby`, `state`, `event`, `started`, `error`, `resume_failed` |

`action.kind` — `deploy`, `attack`, `transfer`, `end`, `propose`, `alliance`, `tribute`, `cede`, `call`, `respond`, `aid`, `break`

- 모든 주사위·전투·외교 판정은 **서버**에서 수행합니다. 클라이언트는 표시만 합니다.
- 방 상태는 메모리에 저장됩니다(서버 재시작 시 초기화). 방장이 나가면 다음 사람에게 넘어가고, 진행 중 나간 자리는 AI가 이어받습니다.
- 접속이 끊긴 플레이어의 턴은 75초(차례 시작 때 이미 끊겨 있었으면 20초) 뒤 자동 종료됩니다.
- 30분간 아무도 접속하지 않은 방과 12시간이 지난 방은 자동 정리됩니다.

### 보안 · 개인정보

- 이름은 최대 12자로 정리하고, WebSocket 메시지는 16KB·분당 60개로 제한합니다.
- 정적 파일은 `public/` 밖으로 나갈 수 없습니다.
- 계정·결제·광고·추적 스크립트가 없습니다. 이름과 방 코드 외에는 저장하지 않으며, 브라우저 `localStorage`에는 재접속용 방 코드·토큰만 둡니다.

## ⚠️ 알려진 제한

- 서버 메모리 기반이라 **수평 확장(다중 인스턴스)에는 Redis 같은 공유 저장소가 필요**합니다. 개인·친구 단위 플레이라면 단일 인스턴스로 충분합니다.
- 무료 호스팅의 슬립/콜드 스타트 동안에는 WebSocket 연결이 잠시 끊길 수 있습니다. 클라이언트가 자동 재연결합니다.
- iOS 저전력 모드에서는 진동이 동작하지 않을 수 있습니다.
